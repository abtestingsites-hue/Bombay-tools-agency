# Bombay Tools Agency — Local Assets Guide

This directory houses all static imagery used across the website. 

To replace any image with your shop's actual photography, simply save your new image with the **exact same filename** in its respective folder. No code modifications or database updates are required.

## Directory Structure & Recommended Dimensions

### 1. `/hero/`
- **`hero-tools.jpg`**: Main showcase photography displayed in the homepage hero banner card.
  - *Recommended Aspect Ratio*: 4:3 or 16:10 (e.g. `1200 x 900` or `1600 x 1000`)
  - *File format*: JPG or WebP (under 250KB for fast loading)

### 2. `/categories/`
Square to landscape ratio for category cards:
- **`electrical-materials.jpg`** — Cables, modular switches, conduit, distribution boxes
- **`hardware-fasteners.jpg`** — Fasteners, SS bolts, hinges, mortise locks
- **`plumbing-materials.jpg`** — CPVC/UPVC pipes, brass fittings, valves
- **`construction-materials.jpg`** — Waterproofing, tile adhesives, binding wire
- **`bathware-sanitaryware.jpg`** — Faucets, showers, wall mixers, SS sinks
- **`tools-accessories.jpg`** — Angle grinders, drills, tape measures, blades
- **`pumps-equipment.jpg`** — Submersible pumps, monoblock pumps, motors
  - *Recommended Aspect Ratio*: 16:9 or 4:3 (e.g. `800 x 500` or `800 x 600`)

### 4. `/branding/`
- **`placeholder.jpg`** — Fallback image shown if a product does not have an image assigned.
